## Mec_Wheel ROS 2 Package

# 1. 구동 아키텍처 (System Architecture)
* **`Aru_Tracker` (비전 파트)**: 카메라 프레임 기준 마커의 x, y, z 거리를 계산해서 Publish. 추가로 마커 인식 여부와 별개로 위성 몸체의 Depth 평균값을 `target_depth`로 상시 Publish.
* **`Mec_Wheel` (제어 파트)**: `Aru_Tracker` 데이터를 Subscribe 하여 콜백 함수로 거리와 헤딩 변수를 즉시 최신화. FSM(유한 상태 머신) 로직에 따라 이동 궤적을 계산하고 `Twist` 형태의 제어 명령을 Publish.
* **`Mec_i2c` (하드웨어 파트)**: `cmd_vel`을 Subscribe 하고, 이를 실제 모터 제어를 위한 I2C 전기적 신호로 변환하여 구동.

# 2. 핵심 구현 알고리즘 (Core Features)
### 2.1. 5 프레임 이동 평균 필터 (Moving Average Filter)
로봇 팔 제어 주파수(30fps, 0.033초)와의 데이터 동기화를 위해, **최신 5개 데이터의 이동 평균**을 사용. `collections.deque`를 활용해 카메라의 ArUco 위치 벡터와 Depth 데이터의 잔진동(Jitter) 및 노이즈를 효과적으로 제거하여 제어의 안정성을 극대화.

### 2.2. ArUco + Depth 센서 퓨전 (Failsafe)
대상 위성의 반대편에 위치하여 ArUco 마커가 보이지 않는 블라인드(Blind) 구간에서도 자기 위치를 추정.
* 비전 노드로부터 카메라 정중앙의 표면 깊이 값(`/target_depth`)을 지속적으로 수신합니다.
* 마커가 없을 때는 이 Depth 값을 피드백으로 삼아 **1.5m 궤도 반경을 상시 유지하며 공전(Wall-following 방식)**.
* 허공을 인식해 뎁스가 튀는 급발진을 막기 위해 유효 거리(0.1m ~ 2.5m) 필터링 안전장치가 적용.

### 2.3. 실시간 `dt` 기반 다중 축 PD 제어
고정된 제어 주기를 사용할 때 발생하는 미분항(D)의 튐 현상을 방지하기 위해, 매 루프마다 **실제 시간차(`dt`)를 계산하여 제어 수식에 반영**하는 정밀 PD 제어기를 구현. 전진/후진(Dist), 좌우 측면 이동(Lat), 제자리 회전(Head) 3축을 동시에 제어하여 목표 궤적을 부드럽게 추종.

### 2.4. 로봇 팔(Mirobot) 협업을 위한 상태 콜백
이동 중 발생하는 카메라의 모션 블러 데이터를 로봇 팔이 잘못 참조하지 않도록 제어 동기화 기능을 포함.
* 휠이 이동 중일 때는 `/wheel_status` 토픽으로 `MOVING`을 발행합니다.
* 최종 목표 지점(0.3m)에 도달해 **기체가 완전히 정지하면 `STOPPED` 신호를 발행**.
* 로봇 팔 노드는 이 `STOPPED` 콜백을 받은 직후 **0.2초의 딜레이**를 대기하여 기체의 기구학적 잔진동이 완전히 멈춘 것을 확인한 뒤, 안정화된 5개 평균 좌표값을 기반으로 G-code를 생성 및 전송.

# 3. 유한 상태 머신 (FSM) 제어 흐름

1. **`BLIND_ORBIT` (탐색 및 공전)**
   * 마커가 보이지 않을 때 실행.
   * 시계 반대 방향으로 공전하기 위해 측면 게걸음(y축)과 제자리 좌회전(z축)을 조합.
   * `target_depth`를 활용하여 대상 위성과의 거리를 1.5m로 유지.
2. **`VISUAL_ALIGN` (마커 발견 및 정렬)**
   * 0.5초 이내에 유효한 마커 데이터가 수신되면 진입.
   * 거리를 1.5m로 유지하면서, 카메라 중앙선(x=0)과 마커가 일치하도록 좌우 치우침 오차가 5cm(0.05m) 이내가 될 때까지 PD 제어기로 부드럽게 정렬.
3. **`APPROACH` (도킹 접근)**
   * 중앙 정렬과 1.5m 거리 유지가 완벽히 맞춰지면 진입.
   * 정렬 상태를 계속 유지한 채로 목표 거리인 0.3m 지점까지 거리에 비례하여 부드럽게 감속하며 전진.
4. **`STOP` (최종 정지)**
   * 0.3m 지점에 도달하면 모든 모터의 속도를 0으로 설정.
   * `/wheel_status`에 `STOPPED` 메시지를 퍼블리시하여 로봇 팔 동작 프로세스 트리거.

# 4. ROS 2 Interfaces (통신 토픽)

### 📥 Subscribed Topics
* `/aruco_poses` (`geometry_msgs/PoseArray`): Aru_Tracker로부터 수신하는 ArUco 마커의 3D 위치 (x, y, z) 벡터.
* `/target_depth` (`std_msgs/Float32`): 카메라 정중앙 픽셀(위성 외벽)의 물리적 거리값.

### 📤 Published Topics
* `/cmd_vel` (`geometry_msgs/Twist`): Mec_i2c 노드로 전달하는 메카넘 휠의 x, y 선속도 및 z 각속도 명령.
* `/wheel_status` (`std_msgs/String`): 로봇 팔 제어 동기화를 위한 현재 휠 동작 상태 (`MOVING` 또는 `STOPPED`).
